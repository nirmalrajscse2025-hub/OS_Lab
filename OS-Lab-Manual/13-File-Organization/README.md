# Experiment 13: File Organization Techniques

These programs create their own data files (`student.dat`, `random.dat`,
`index.txt`, etc.) when you run them — that's expected and part of the
demonstration. No data files are committed here; they'll appear after
you run the programs.

```
gcc 1_sequential_file.c    -o sequential_file    && ./sequential_file
gcc 2_direct_random_file.c -o direct_random_file  && ./direct_random_file
gcc 3_indexed_file.c       -o indexed_file        && ./indexed_file
```
